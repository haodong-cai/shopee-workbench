# 店铺授权说明

工作台通过 Shopee 开放平台（Shopee Open Platform）的官方接口读取店铺数据。你需要：

1. 一个开放平台**应用**（拿到 Partner ID 和 Partner Key）；
2. 用卖家账号给这个应用**授权店铺**（工作台自动换取令牌并保存在本机）。

> 开放平台的页面、应用类型和审核要求会调整，以下步骤以 [Shopee 开放平台](https://open.shopee.com/) 后台当前显示为准。

## 第一步：创建开放平台应用

1. 打开 <https://open.shopee.com/>，点击右上角登录 / 注册开发者账号，按要求完成开发者资料（个人或企业）。卖家自用一般选择“自研系统 / Seller In House System”类的身份。
2. 进入 **App Management → App List**，创建应用。
3. 按需要勾选 / 申请接口权限。本工作台用到的接口模块：
   - **Shop**（店铺信息、仓库）
   - **Order**（订单列表与详情）
   - **Payment**（订单结算明细）
   - **Ads**（广告余额、广告表现）
   - **Returns**（退货退款）
   - **Product**（商品与规格，用于把广告商品映射到 SKU）
4. 提交审核。审核通过、应用上线（Live）后，在应用详情里可以看到 **Live Partner ID** 和 **Live Partner Key**。
5. 如果应用设置里有 **Redirect URL Domain / 回调地址** 一项，填写 `http://127.0.0.1:8787`（或你实际使用的地址，见下文“回调地址”）。

测试阶段也可以用应用的 **Test Partner ID / Key** 配合沙箱环境（`.env` 中 `SHOPEE_ENVIRONMENT=sandbox`），但沙箱里没有真实店铺数据。

## 第二步：填写 `.env`

在工作台根目录把 `.env.example` 复制为 `.env`，填写：

```ini
SHOPEE_PARTNER_ID=你的 Partner ID（纯数字）
SHOPEE_PARTNER_KEY=你的 Partner Key
SHOPEE_ENVIRONMENT=live
```

保存后**重启工作台**（`.env` 只在启动时读取）。

⚠️ Partner Key 等同于密码：只放在本机 `.env`，不要发到聊天、截图或提交到 GitHub（`.env` 已被 `.gitignore` 排除）。

## 第三步：授权店铺（推荐方式）

1. 确认工作台已启动，在**运行工作台的那台电脑**上用浏览器打开：

   <http://127.0.0.1:8787/auth/start>

   （也可以在“数据与接入”页点“授权 / 追加店铺”。）
2. 页面会跳转到 Shopee 授权页。登录卖家账号：
   - 用**主账号**（Main Account / 商户账号）登录：可一次勾选多个站点的店铺；
   - 用**单个店铺账号**登录：一次授权一家店。
3. 确认授权后，浏览器回到 `http://127.0.0.1:8787/auth/callback`，看到“授权成功”即完成。令牌保存在本机 `.local/shopee-auth.json`。
4. 回到工作台“数据与接入”，点“全部同步”。

**追加店铺**：再走一遍上面的流程即可。单店授权会合并到已有列表，不会覆盖之前的店铺。

## 备用方式：命令行授权

如果你的应用回调地址不能填 `127.0.0.1`（例如只能填自己的网站域名），用命令行：

```bash
npm run auth -- link https://你登记的回调地址
```

1. 复制输出的链接到浏览器打开（**5 分钟内有效**，过期重新生成），登录并确认授权。
2. 授权后浏览器会跳到你的回调地址，页面打不开也没关系，**复制地址栏里的完整地址**（里面带有 `code=...&shop_id=...` 或 `main_account_id=...`）。
3. 运行：

   ```bash
   npm run auth -- "粘贴的完整地址"
   ```

   看到“授权成功”即可。授权码只能使用一次，且有效期很短，请尽快完成。

也可以在 `.env` 里设置 `SHOPEE_REDIRECT_URL=你的回调地址`，这样 `/auth/start` 会使用这个地址。

## 令牌与有效期

- 访问令牌（access token）几小时就会过期，工作台在需要时自动用刷新令牌续期，无需手动操作。
- 店铺授权本身也有有效期（通常为一年左右，以授权页显示为准）。到期、卖家在后台取消授权、或更换了应用后，需要重新授权。
- 一家店同一时间只应授权给一套工作台使用。多台电脑各自授权同一家店，可能导致刷新令牌互相失效；多人使用请用“局域网共享”访问同一台主机。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 打开 `/auth/start` 显示“请先在 .env 里填写……” | `.env` 未填写或填写后没有重启工作台 |
| 授权页提示 redirect / 回调地址不合法 | 在开放平台应用设置里登记回调域名，或改用命令行方式 |
| 回调页显示“虾皮拒绝授权交换（error_auth 等）” | 授权码过期或已使用过、Partner ID/Key 填错、环境（live / sandbox）不匹配；重新从 `/auth/start` 开始 |
| 同步提示“授权文件与当前应用不一致” | 更换过 `.env` 的 Partner ID，请重新授权 |
| 同步提示“接口拒绝请求，请核对该模块的接口权限” | 应用没有对应模块的接口权限，到开放平台申请后重新授权 |
| 同步提示“令牌刷新状态待核对” | 上次刷新中途中断，重新授权一次即可 |
| 局域网里的同事打开授权页显示“只能在主机上授权” | 授权必须在运行工作台的电脑上操作 |

## 撤销授权

- 在卖家中心或开放平台取消对该应用的授权；
- 在本机删除 `.local/shopee-auth.json`（会删除所有店铺的令牌）。
