# 虾皮控制中台（Shopee Workbench）

作者：**云舟渡晚** · 小红书号 `563480199` · 抖音号 `Die_Alpen` · [MIT 许可证](LICENSE)

一个在自己电脑上运行的虾皮（Shopee）多站点运营工作台。数据通过 Shopee 开放平台官方接口**只读**同步，全部保存在本机，不经过任何第三方服务器。

支持站点：马来西亚 MY、泰国 TH、越南 VN、菲律宾 PH、巴西 BR（巴西暂不参与毛利试算）。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 今日概览 | 多店铺汇总：有效订单、销售额、净收入、广告消耗、待出库，“需要处理”清单自动汇集余额将尽、同步失败、高取消率等事项 |
| 订单 | 订单列表、发货时效、取消分析 |
| 商品排行 | 按链接 / SPU 统计销量、成交额与贡献 |
| 断货预警 | 导入仓库系统的在库表、在途表，结合近 7 天销量预测断货时间，给出“暂停广告 / 降低预算”建议 |
| 平台扣费 | 佣金、服务费、手续费等逐单拆解 |
| 广告与余额 | 广告组表现、全店托管 GMV Max、广告余额预计可用天数 |
| 退货售后 | 按“退货退款 / 仅退款”和处理状态分组 |
| 毛利试算 | 海外仓 / 跨境逐单预估毛利（需填写成本档案和费用参数） |
| 批量上架 | 商品表 → 官方上架模板字段映射 → 本地校验 → 导出 Excel |
| 数据与接入 | 同步矩阵、定时同步、每日汇率、局域网访问 |

统计周期可在顶栏切换：昨日 / 近 3 天 / 近 7 天 / 近 30 天。

## 快速开始

### 1. 准备环境

- Windows 10/11（其他系统可用 `npm` 命令启动）
- [Node.js](https://nodejs.org/) 20.19+ 或 22.12+
- 一个 Shopee 开放平台应用（Partner ID 和 Partner Key），申请方法见 [店铺授权说明](docs/授权店铺.md)

### 2. 下载并配置

```bash
git clone <你的仓库地址> shopee-workbench
cd shopee-workbench
copy .env.example .env                                   # macOS / Linux 用 cp
copy config\business.example.json config\business.json  # 经营参数，可稍后再填
```

用记事本打开 `.env`，填写 `SHOPEE_PARTNER_ID` 和 `SHOPEE_PARTNER_KEY`。

### 3. 启动

双击 **`启动工作台.cmd`**。首次运行会自动安装依赖、构建界面，然后打开浏览器 <http://127.0.0.1:8787>。

命令行方式：

```bash
npm install
npm run build
npm start
```

### 4. 授权店铺

工作台运行后，在**同一台电脑**的浏览器打开 <http://127.0.0.1:8787/auth/start>，登录卖家账号并确认授权即可。详细步骤和常见问题见 **[店铺授权说明](docs/授权店铺.md)**。

### 5. 同步数据

进入左侧“数据与接入”，点击“全部同步”。之后工作台运行期间会按计划自动同步（默认每天 08:30 全量同步，之后每 4 小时刷新订单和退货，可在同页修改）。

## 使用说明

### 填写经营参数（毛利试算需要）

`config/business.json` 控制所有和你自己业务相关的数字。**默认全部留空**，留空的项目在页面上显示“待补”，不会按 0 计算。修改后重启工作台生效。

| 字段 | 含义 |
| --- | --- |
| `overseasFees.<站点>.packingPerOrder` | 海外仓每单打包费（人民币） |
| `overseasFees.<站点>.transportPerPair` | 海外仓每双鞋运输费（人民币）；配件不计双数 |
| `crossBorderPerPair` | 跨境订单每双鞋的头程 / 处理费（人民币） |
| `leadDays.<站点>` | 断货预警用的头程天数（也可在“断货预警”页面填写） |
| `safetyDays` | 安全天数，默认 3 |
| `skuPrefixes.shoe` / `.accessory` | 按 SPU 编码前缀自动判断“鞋 / 配件”的正则，例如 `"^SH"`；留空则只用人工清单 |
| `knownAdCampaignIds` | 可选，需要额外补查的广告组 ID |

> 某站点的海外仓费用没填时，该站点不进入毛利试算；其他功能（订单、广告、退货等）不受影响。

### 导入采购成本

毛利试算和商品贡献需要每个 SKU 的采购成本（人民币）。参照 `templates/单品成本表模板.csv` 和 `templates/组合装表模板.csv` 整理好自己的表格（CSV 需保存为 UTF-8，也支持 XLSX），然后运行：

```bash
npm run import-costs -- 我的单品成本表.xlsx 我的组合装表.xlsx
```

- 单品表必需列：`SKU`、`采购成本`；可选列：`SPU`、`名称`、`用途`（填“鞋”或“配件”）。
- 组合装表必需列：`组合SKU`、`子SKU`、`数量`。组合装成本按部件自动相加。
- 结果保存为 `.local/product-cost-catalog-日期.json`，工作台自动读取日期最新的一份。成本更新后重新导入即可。
- 这里的 SKU 要和虾皮后台商品规格里填写的 SKU 一致。

### 断货预警

在“经营 → 断货预警”导入仓库系统导出的两张表（按表头自动识别，格式参照 `templates/在库表模板.csv`、`templates/在途表模板.csv`）：

- **在库表**：`SKU`、`可用库存`、`仓库`
- **在途表**：`入库单号`、`仓库`、`创建时间`、`SKU`、`预约数量`

仓库名需以站点代码开头（如 `TH-01`、`MY_KL`），用于判断所属站点。先在页面上方填写各站点头程天数，才会开始预测。

### 局域网共享

同一网络的同事用浏览器打开主机地址（如 `http://192.168.1.20:8787`）即可使用，地址在“数据与接入 → 局域网访问”查看。可在主机上开启访问码。首次启动时 Windows 防火墙提示请允许“专用网络”。授权店铺、修改局域网设置只能在主机上操作。

### 批量上架

“工具 → 批量上架”：导入商品 CSV/XLSX 和从卖家中心下载的官方类目模板，逐列确认对应关系，本地校验通过后导出，再到卖家中心上传。本地校验通过不代表平台校验通过。

## 数据与隐私

- 所有数据只保存在本机的 `.local/` 目录：授权令牌、同步快照、成本档案、毛利记录等。
- `.env`（应用密钥）、`config/business.json`（经营参数）、`.local/`、日志都已在 `.gitignore` 中排除，**不会被提交**。分享或提交前请再确认一次 `git status`。
- 工作台对店铺只做读取，不会修改商品、价格、广告或订单。
- 不要把密钥、令牌写进聊天、截图、前端代码或 Issue。

## 开发

```bash
npm run dev      # 界面 http://127.0.0.1:5173（热更新），服务 8787
npm run build    # 构建界面到 dist/
npm test         # 运行测试（先 build 一次，局域网测试需要 dist/index.html）
npm run auth     # 命令行授权工具，见 docs/授权店铺.md
```

技术栈：React 19 + Vite（界面）、Express 5（本地服务）、Node 内置测试。测试使用 `tests/helpers/business.test.json` 中的虚构参数。

目录结构：

```
server/        本地服务与各模块（同步、毛利、断货预警、授权……）
src/           界面
scripts/       命令行工具（授权、导入成本）
config/        经营参数模板（business.example.json）
templates/     导入表格模板
tests/         自动化测试
docs/          使用文档
```

## 常见问题

**启动时提示“8787 端口已被其他程序占用”**：关闭占用该端口的程序，或已有一个工作台在运行。

**同步失败 / 提示授权文件与当前应用不一致**：`.env` 的 Partner ID 和授权时用的不一致，请重新授权。

**毛利全部显示“待补”**：检查是否已导入成本档案、`config/business.json` 是否填写了对应站点的费用，以及是否同步过订单和平台扣费。

**修改 `.env` 或 `config/business.json` 后没变化**：需要重启工作台（关闭后台 node 进程后再双击启动）。
